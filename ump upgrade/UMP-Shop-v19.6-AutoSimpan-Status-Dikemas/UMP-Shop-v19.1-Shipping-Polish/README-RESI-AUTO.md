UMP Shop v19.1 — Kode Pengiriman Otomatis

Admin > Pesanan Online:
1. Pilih jasa pengiriman.
2. Klik “Buat Kode Acak” untuk mengisi kode internal UMP yang unik dan tidak berurutan.
3. Klik “Simpan Pengiriman”.

PENTING: Kode UMP-... dibuat oleh website untuk referensi/pelacakan internal. Kode ini BUKAN nomor resi resmi dan tidak bisa dipakai untuk melacak paket di J&T, J&T Cargo, SPX, atau AnterAja. Untuk resi resmi, masukkan nomor yang diterbitkan kurir. Penerbitan resi resmi otomatis membutuhkan integrasi API kurir/agregator dan kredensial akun bisnis.
